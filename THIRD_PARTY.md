# Third-party material

The production source comes from the owner's MIT BlueMap Chipped Add-on. The
module contains no Athena source, class, model, texture, translation, capture,
or derived mesh. Athena 4.0.6 supplied behavior and installed-resource evidence
to the original add-on, not implementation source for this module.

JUnit is a test-only dependency. The production POM and Gradle module metadata
declare no dependency.
